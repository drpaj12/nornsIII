## Method notes

* Soft seeds are `--read_initial_place_file` with the cluster layout; `full` keeps the analytic order inside a cluster, `inter` shuffles it.
* The hard arm is `--read_vpr_constraints` with one region per cluster; the intra-cluster arrangement is VPR's, so there is one hard variant.
* VPR's placement macros (adder carry chains, mult_36) are respected: chains move as a vertical run, mult macros and pads stay anchored.
* Crossover = the largest `--anneal_auto_init_t_scale` S at which the cold start still routes shorter than the unseeded run at the same S; the start temperature recorded by VPR is S x its automatic estimate.
* Retention = fraction of a seed's cluster CLBs whose exit position is inside the cluster's seed bounding box; displacement = mean CLB distance from the seed slot.
* Agent defaults: (1) the Loki L0 graph.json is built by Norns from the same Odin III BLIF because Loki's own key.json uses Odin API names that do not join to VPR atom names; the clusterings are Loki's `loki.analysis.cluster` code. (2) The hard arm constrains regions only, so it has no full/inter split. (3) Pad CLBs and mult_36 macros stay anchored; adder carry chains move as a vertical run. (4) One VPR run per configuration at `--seed 1` (deterministic). (5) Urd is degenerate (one cluster) on designs whose Odin hierarchy has a single module.
* VPR checkpointing is a stock flag (`--place_checkpointing`, default on), not a patch; the on arm is the main matrix, the off arm repeats the cold-start scale sweep.


## Remaining matrix (continuation lane)

Designs not started in this lane, smallest first: stereovision0, stereovision1, mkDelayWorker32B, stereovision2, blob_merge.
Per design, run exactly:

    scripts/run_design.sh <design>

then extend the crossover and the checkpointing control if the lane has time:

    . scripts/env.sh && $NR_PY scripts/matrix.py crossover <design>
    . scripts/env.sh && $NR_PY scripts/matrix.py checkpoint <design>
    . scripts/env.sh && $NR_PY scripts/backfill.py && $NR_PY scripts/report.py
