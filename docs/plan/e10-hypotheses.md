# Hypothesis register: E10 algorithm parameter sweep (docs/plan/e10.md)

Register for the paper step, in the format of `docs/paper/hypotheses.md` (branch docs/hypotheses). Written 2026-10-28 in the E10 fix round; every number is copied from `data/e10/ratios.csv` (produced by `scripts/e10_tables.py`) and Section 8 of `docs/plan/e10.md`.

Verdict words as in the paper register: USEFUL = supported (here: the 95% interval excludes 1.000, direction stated); DISMISSED = not supported (here: no-op, byte-identical to the base); INCONCLUSIVE = interval includes 1.000. Section 6 of e10.md fixed the comparisons and the interval but no thresholds; the verdict rule is therefore **POST-HOC** (dated entry, Section 13) and labelled so. Holm-adjusted bootstrap p-values (36 tests, the `all` rows) are reported beside it. Pre-registration time: e10.md commit bfe3b7f (2026-10-28 06:53). Ratios are level over the `vpr_sa` base, lower is better for every measure; LUTs are Odin III netlist LUTs.
Caveats: `k4` also removes the hard blocks (confound stated in Section 1); the external placer arms inherit the `vpr_ap` seed-1 positions for hard blocks and pads and nextpnr has no timing model (H0 bias); the placer arms exclude the designs where an arm failed (Section 8). Designs are not independent draws from a population; the interval is over this set of 35.
