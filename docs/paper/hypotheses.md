# Hypothesis register: The Norns III paper (norns.tex, rounds 1 to 9 and the heap studies)

Step 1 of the restructure (brief `papers-hypothesis-register.md`, 2026-10-28) wrote this register from origin/main be9096c (nornsIII #17). Step 2 (brief `papers-rewrite-step2.md`, 2026-10-28) updates it against origin/main 21fd81e (nornsIII #19) and applies Peter's decisions: fragile or narrow supported rows are POSSIBLY GOOD; rounds without thresholds fixed in advance are INCONCLUSIVE where the numbers do not decide; the H22 gain is withdrawn (oracle leak) and replaced by the H22' re-run (docs/plan/round8-h22.md, data/analysis/r8-results.json); H37 is restated per alignment level; the E10 register (docs/plan/e10-hypotheses.md) is added; untested ideas are listed at the end. Every number is copied from a committed file named in the row. The paper text does not use the framing column; it only states each hypothesis and what the experiment showed.

Verdict words: USEFUL = supported under the round's own decision rule and not fragile; POSSIBLY GOOD = supported but narrow or fragile (small n, a clause added after the rule, or a rule chosen after the data), main text only with the fragility stated, never as proof of an innovation alone; DISMISSED = not supported (failed); INCONCLUSIVE = neither (power or rule limit stated). The first word of every verdict cell is the verdict, so the counts can be computed from the table (docs/paper/check_register.py). Never upgraded beyond the committed status. Where the paper's own later text shows a supported hypothesis to be an artefact, the row says so and the verdict column states the effect on the innovation's value.
Framing: PRE-REGISTERED = the rule text was committed before the round's first measurement (cited); RECONSTRUCTED = built from the round's stated aim (cited), never claimed as pre-registered. In-repository commit times are the only registration there is (no outside registry).
